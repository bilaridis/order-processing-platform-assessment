# Presentations

Outline of the walkthrough (about 30 minutes), in the order of the documents:

1. The problem and the assumptions (2 min)
2. Seven services, why these boundaries, one function per feature (5 min)
3. The order lifecycle: received as `Submitted`, accepted or rejected by message (5 min)
4. Failure handling: Service Bus only, no outbox, idempotency, compensations, dead letters (5 min)
5. Non-functional requirements, targets and trade-offs (5 min)
6. Live demo: place, confirm, ship, refused cancel; a failing boundary test (5 min)
7. What was left out on purpose and the build order (3 min)
8. How AI was used and where judgement was applied (3 min)
